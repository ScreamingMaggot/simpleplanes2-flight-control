【教程总览】
--------------------------------------------------------------------------------

Funky Trees（简称 FT 或 "Funky"）是内置于 SimplePlanes 与 SimplePlanes 2 中的标准化
编程语言。它提供了一整套强大功能，让玩家可以构造远比"直接控制"输入（Throttle、Pitch、
Roll、Yaw 等）复杂得多的控制与输入系统。

这份非官方教程通过一系列"跟做式"演示（都以同一架"示例载具"为对象）来介绍 Funky Trees
的基本概念与原理。它并不追求面面俱到，示例也未必适用于所有场合；但这些例子很容易被改编、
扩展到你自己的作品上。

本教程同时面向 SimplePlanes 1 与 SimplePlanes 2 编写；两者有差异之处会单独标注，但内容
对两个游戏都适用。若需要更详细的文档与完整的功能清单，请查阅本站的 Reference（参考）区。

教程按复杂度递增排列：

  1. Introduction          入门：什么是 Funky Trees
  2. Rules of Funky Trees  语言规则：格式、语法与执行标准
  3. Example Craft         示例载具：本教程使用的示例飞机
  4. Canopy Hinge          可切换座舱盖铰链：基础 FT 输入与输入钳位
  5. RPM Gauge             发动机转速表：把部件输出当作 FT 变量
  6. Custom Landing Gear   自定义起落架：需要精确时序的经典应用
  7. Automatic Flaps       自动襟翼：在表达式中使用实时飞行数据
  8. Target-Tracking Camera 目标追踪相机：把机体状态与控制输入组合成复杂表达式


--------------------------------------------------------------------------------
【1】Introduction　入门：什么是 Funky Trees？
--------------------------------------------------------------------------------

你大概想知道：有些玩家用来控制自己作品部件的程序/脚本，到底是什么东西？也许你只是想看懂
这些玩家在做什么，也许你想给自己的作品也加一点自动化。你见过、甚至飞过那些带华丽自动功能的
飞机——但这些功能怎么做出来？

答案当然是靠"魔法"——Funky Trees！Funky Trees 是内置于 SimplePlanes 和 SimplePlanes 2
的编程语言，允许你使用复杂得多的表达式与逻辑（也就是"数学"）来控制作品上的各种部件和输入。
自动配平、自定义起落架、弹舱门、数字 HUD……天空才是极限。

Funky Trees 是一门函数式编程（functional programming）语言：这意味着每个表达式都是一个
函数，会返回一个单一的值，而这个值又可以作为变量传给其它表达式。本质上，一切都是一个数学方程，
由你来定义方程是什么、变量有哪些。

从本文档的篇幅就能看出，Funky Trees 若被充分利用会极其强大。但能力越大、复杂度越高，很容易
让人不知所措。所幸 Funky Trees 也能做很多非常简单的编程——即使你没有任何编程经验，这些简单
用法也是入门的好起点。

前置知识：本教程的讲解假定你具备代数与三角学的基础。某些高级 Funky Trees 公式需要微积分
知识才能正确理解与实现，但本教程聚焦于基础部分。


--------------------------------------------------------------------------------
【2】Rules of Funky Trees　语言规则
--------------------------------------------------------------------------------

总体上，Funky Trees 就是：选择你想用的输入 → 让这些输入经过各种数学运算 → 决定拿结果做什么。
具体做法见后续章节，但在继续之前，有几条关键规则需要知道。

■ 语法（Syntax）

  · 拼写很重要：Altitude 与 Atlitude 不是一回事。
  · 大小写很重要：Altitude 与 altitude 是不同的东西。
  · 运算优先级：数学运算遵循标准运算顺序（详见 Operators 运算符一节）。
  · 空白字符：空格会被忽略。Pitch * 0.5 与 Pitch*0.5 处理结果相同。但空格不会被
    自动删除，它有助于排版与可读性。

■ 执行（Execution）

  · 更新频率：表达式每个物理帧（physics tick）求值一次。物理质量设置越高，更新频率越高。
  · 错误处理：若表达式非法或产生了非法输出，游戏要么把输出当作 0，要么（对于非法变量）
    直接拒绝保存。

■ 表达式类型（Expression Types）

  Funky Trees 使用三种基本表达式类型。任何 Funky Trees 公式中的每个元素与表达式，都可以
  归入这三类之一：

  · 变量（Variables）
  · 函数（Functions）
  · 运算符（Operators）

这架飞机已经能飞，功能也"技术上"都能用。先试飞一下，感受它的操纵性；后面我们会更多地飞它，

你可能已经注意到：座舱盖（canopy）和襟翼（flaps）是被同一个 VTOL 滑块同时操控的。这显然不

接下来的各节会带你一步步给这架示例机添加多种 Funky Trees 功能，演示如何把 Funky Trees 的
逻辑原理应用到自己的作品上。本教程覆盖的功能，按复杂度递增：

  · 可切换座舱盖铰链（Toggleable Canopy Hinge）
  · 发动机转速表（Engine RPM Gauge）
  · 自动襟翼（Automatic Flaps）
  · 自定义起落架（Custom Landing Gear）
  · 目标追踪相机（Target Tracking Camera）

【4】Toggleable Canopy Hinge　可切换座舱盖铰链
--------------------------------------------------------------------------------

座舱盖铰链当前使用 VTOL 输入（由玩家拖动 VTOL 滑块决定）。这种做法有几个问题：

  · 用按钮开盖会方便得多。
  · 铰链会"反向"旋转，把座舱盖弄断。

我们要修改座舱盖旋转器（rotator）的输入控制来解决这两个问题。

【操作步骤】
定位到座舱盖旋转器（它在座舱后壁上，涂成黄色）。选中它，打开 Part Properties 菜单，
然后 Ctrl + 左键 点击 Input 选项（写着 VTOL 的灰框）。这会打开 Funky Trees 输入窗口
——一个文本框，你可以在里面写用作该部件输入的 Funky Trees 表达式。它当前显示：

    VTOL

■ 用激活组作输入（Activation Group Input）

首先，把旋转器的输入改为使用一个激活组，而不是 VTOL 滑块。这样做有两个好处：现在可以用座舱
按钮或单击来控制座舱盖；而 VTOL 滑块可以被让给其它需要更精细控制的功能。

把输入窗口里的内容替换为：

    Activate8

这个表达式告诉旋转器使用激活组 8 作为输入。激活组 8（以及其它激活组）是一个布尔变量：
开启时输出 True，关闭时输出 False。当它被用作输入时，True 会自动转换为 1（False
转换为 -1）——于是我们就有了一个按钮，把旋转器设为 1 还是 -1 取决于激活组 8 是否开启。
换句话说，激活组 8 现在控制座舱盖了。

  ※ 想换用别的激活组，把 Activate8 换成 ActivateN，其中 N 对应你想用的激活组编号。

■ 输入钳位（Input Clamping）

现在试飞，你会发现座舱盖会自动打开——因为激活组 8 默认就是开启的。但你也会发现：关掉它时
座舱盖关得太深、撞进了机身。不行！

问题在于：旋转器既能接受正数也能接受负数，也就是它可以朝两个方向运动。用 VTOL 滑块时也有这个
问题，但有一个简单的修法：加一个钳位限制器（clamp limiter）。

  ※ VTOL 是一个范围数值控制输入，它根据 VTOL 滑块的位置产生某个区间内的数——本例中为
  ※ -1 到 1。

为了加钳位限制，我们用 clamp 函数。由于我们希望激活组 8 开启时旋转器仍能到达上限，区间上端
保持 1，下端钳到 0，以防旋转器把座舱盖往错误方向推。好在这是个常见用法，所以有一个现成的
特化版本：clamp01。

  ※ clamp01(x) 在功能上等价于 clamp(x, 0, 1)。

把 clamp01 加到输入窗口里，如下：

    clamp01(Activate8)

或者，你也可以用普通 clamp 函数写（功能完全相同）：

    clamp(Activate8, 0, 1)

现在再试飞，你会看到：关掉激活组 8 时，座舱盖会回到关闭位置。

  → 下一节：我们会修改座舱里的一个仪表，用来显示发动机输出的数值。

【5】Engine RPM Gauge　发动机转速表
--------------------------------------------------------------------------------

Funky Trees 的另一类常见用法是使用部件输出（part outputs）。部件输出有很多种用途，取决于
具体作品以及所用的是哪些输出；本教程中，我们要做一个简单的转速表（tachometer），读取发动机
的一个输出。

  ※ 部件输出是绑定到作品上特定部件（如发动机、旋转器）的数值变量。更多内容见 Reference 的
  ※ 部件变量一节。

打开部件输出菜单的具体方式，在 SimplePlanes 1 与 SimplePlanes 2 中不同：

  · SimplePlanes 1：移到飞机尾部，选中螺旋桨（propeller）部件。在 SP1 中，螺旋桨与发动机
    是同一个部件。点击屏幕右侧（Part Properties 选项上方）的箭头打开 Rotate Part 菜单，
    然后按 (x) 按钮（列表顶部）打开 Part Variable Outputs 界面。

  · SimplePlanes 2：移到飞机尾部，选中螺旋桨发动机（propeller engine）部件。在 SP2 中，
    发动机与螺旋桨本身是两个分开的部件。点击屏幕右侧（Part Properties 选项上方）的扳手
    图标打开 Selected Part Options 菜单，然后按带仪表图标的按钮（列表顶部）打开
    Variable Outputs 界面。

菜单打开后，你会看到发动机有两个可用的变量输出：RPM 和 OutputTorque（在 SimplePlanes 1
中为 Thrust）。在 Variable Name 框里输入一个词，就会把那个词设为这台发动机该输出的变量名，
之后就能在其它 Funky Trees 表达式中引用它。

在 RPM 输出对应的字段里输入：

    EngineRPM

这会为这架飞机创建一个新变量 EngineRPM，它会显示发动机当前的 RPM。

创建变量后，移到座舱，选中转速表（在仪表盘上，涂成橙色）。打开 Part Properties 菜单，再
Ctrl + 左键 点击 Input 选项，像之前一样打开 Funky Trees 输入窗口。选中已有文本并删除，
再输入：

    EngineRPM/6000

把 RPM 输入除以 6000，是为了让它能合适地映射进仪表的量程（否则指针会疯狂旋转）；随后再用该
仪表的 Input Multiplier 属性（当前设为 230）进一步"缩放"到仪表量程。这个属性以及其它
属性都已经为本教程预先设好了，现在先不用管它们。

现在再试飞：加大油门时，转速表就会正确显示发动机 RPM 了。你可以在飞行中给螺旋桨施加不同负载，
观察它的变化；不过它会一直停在量程偏低的一侧，因为这台螺旋桨的设计转速区间是 1,000–2,000 RPM。

  → 下一节：我们会同时使用 Funky Trees 输入与部件输出，编写一个简单的自定义起落架机构。

【6】Custom Landing Gear　自定义起落架
--------------------------------------------------------------------------------

现在我们能看清发动机在做什么了，是时候起飞了。你可能已经注意到，飞机的起落架由 VTOL 滑块
控制。这虽然技术上能用，但显然不理想——毕竟起落架是有专用按钮的。

每个起落架舱里有两个旋转器：一个普通旋转器（涂蓝色）控制舱门，一个铰链旋转器（涂浅蓝）控制
起落架支柱本身。在这架飞机上，三个起落架组件的功能完全相同，任选一个开始即可。

■ 起落架变量输入

首先，选中浅蓝色的铰链旋转器。打开 Part Properties 菜单，Ctrl + 左键 点击 Input
选项，像之前一样打开 Funky Trees 输入窗口。选中已有文本并删除，然后输入：

    GearDown ? 0 : 1

这个表达式告诉旋转器使用 GearDown 作为输入。在功能层面，它和之前用在座舱盖铰链上的表达式
本质相同。

  ※ 也可以用 LandingGear 变量代替 GearDown；但注意 LandingGear = 1 表示起落架已收起，
  ※ 而 GearDown = True 表示起落架已放下。

现在载入飞机，你应该能看到：按下起落架按钮时，起落架支柱向上收进起落架舱。对非常简单的起落架
来说，到这里就够了——但舱门的问题仍然存在。

■ 舱门延迟与时序

给旋转器或舱门强制加延迟的方法有很多种，有的更复杂；但最可靠的办法是：直接根据起落架自身的
位置来控制舱门。

理想情况是：起落架收起后舱门关闭；起落架一开始放下，舱门立即打开。直接照抄起落架支柱用的输入
是不行的——那样舱门会和支柱同时关闭，会出现和之前一样的问题。

因此，需要一点简单的"时序"控制：根据起落架自身的角度来控制舱门。

再次选中浅蓝色的铰链旋转器，用之前相同的方法打开 Part Variable Outputs 界面。与发动机不同，
铰链旋转器只有一个可用的变量输出：Current Angle（当前角度）。它输出一个数值，对应该旋转器的
角度（单位：度）。

在 Current Angle 输出对应的字段里输入：

    Gear1

这会为这个旋转器创建一个新变量 Gear1。

接着，选中控制起落架舱门的蓝色旋转器。在它的 Input 框里输入：

    ((abs(Gear1) < 80) | GearDown) ? 0 : 1

这个函数读作："如果 Gear1 的绝对值小于 80（度），或者 GearDown 等于 True，就把输入值
设为 0；否则设为 1。"

这样，当起落架收起超过 80 度后，舱门开始关闭；而一旦下达放下起落架的命令，舱门就会立刻开始打开。

对其余两个起落架组件重复上述步骤（分别用 Gear2 和 Gear3 作为角度变量），即可完成本阶段。

这只是制作自定义可收放起落架的众多方法中（极其简单的）一种；但许多更复杂的方案，本质上仍然是
这一时序原理的某种变体。

【2.0　通用说明】（原文 Misc Notes）

  · 支持标准算术运算符与布尔逻辑，用于构造复杂条件语句。
  · 除非另有说明，系统使用国际单位制（米、秒、牛顿），角度使用"度"。
  · 函数名与变量名严格区分大小写。
  · 所有表达式每帧求值一次；更新频率与游戏的物理质量（physics quality）设置直接相关。


--------------------------------------------------------------------------------
【2.1】数据类型　Data Types
--------------------------------------------------------------------------------

■ Numbers 数字
  表示定量数值，包含整数与浮点数，是连续数学计算与遥测数据的主要类型。
    格式：标准数值写法      示例：1、1314、12.0003、0.334

■ Booleans 布尔值
  表示逻辑状态，主要用于条件语句、开关与二元激活组。
    字面值：True、False
    数值转换：布尔量在 Funky Trees 中是动态类型的。当在数值语境中（与数字类数据一起）求值时，
              会自动转换为特定整数：True → 1，False → -1。
    行为：当独立于其它数据类型求值时，布尔量保持其字面的 True / False 状态。

■ Strings 字符串
  表示文本数据的字母数字字符序列。
    格式：文本必须用双引号（""）括起
    示例："Text"、"Boom 50"、"Cannon"
    用途：用于武器识别，以及作为某些函数的参数。
      · 变量示例：SelectedWeapon 返回当前活动武器的名称字符串。
      · 函数示例：ammo("string") 需要字符串输入来指定要查询的武器。


--------------------------------------------------------------------------------
【2.2】运算符　Operators
--------------------------------------------------------------------------------

■ 算术运算符（遵循标准运算优先级）

    符号    运算        说明
    +       加法        数值相加；也可拼接两个字符串（如 "He" + "llo" = "Hello"）
    -       减法        数值相减，或表示负号
    *       乘法        两数相乘
    /       除法        前数除以后数
    %       取模        相除后返回余数
    ( )     分组        用括号定义求值顺序，括号内先算

    ！注意：不支持隐式乘法，例如 (a)(b) 不合法，必须显式写出 * 运算符。

■ 比较运算符（返回布尔结果 true / false）

    符号    含义        说明
    =       等于        左右相等时返回 true
    !=      不等于      左右不等时返回 true
    >       大于        左值严格大于右值时返回 true
    <       小于        左值严格小于右值时返回 true
    >=      大于等于    左值不小于右值时返回 true
    <=      小于等于    左值不大于右值时返回 true

■ 逻辑运算符（对布尔操作数运算，返回布尔结果）

    符号    运算        说明
    &       布尔与      仅当两个操作数都为 true 时返回 true
    |       布尔或      至少一个操作数为 true 时返回 true
    !       布尔非      取反（如 !true 得 false）

    求值行为：逻辑运算符采用"短路"求值。若 & 或 | 的第一个操作数已能决定最终结果，则第二个
              操作数不会被检查或更新。这可能影响 sum()、rate() 这类基于时间的函数——若它们
              被放在第二个操作数位置。

■ 选择运算符（内联条件逻辑）

    符号    运算        语法          说明
    ? :     三元选择    a ? b : c     判断条件 a：若 a 为 true 则返回 b，否则返回 c

    选择运算符的行为类似 "If-Then-Else" 语句。

【2.3】变量　Variables
--------------------------------------------------------------------------------

变量提供表达式中使用的实时数据，分为「内置系统变量」与「用户自定义变量」两大类。

  · 只读变量（Read-only Variables）：游戏引擎提供的标准数据点。
      - 输入变量 Input Variables：由用户直接交互驱动的值。
      - 状态变量 State Variables：来自仿真的只读遥测与传感器数据。
  · 自定义变量（Custom Variables）：用户扩展定义的数据源。
      - 变量设置器 Variable Setters：带高级逻辑与持久性的全局变量。
      - 部件变量 Part Variables：特定飞机部件独有的局部输出。

  注意：所有变量名区分大小写；变量按帧更新，频率取决于物理质量设置（SP2 中则为服务器
        设定的 tick 速率）。内置变量无法被重定义。

■ 2.3.3　自定义变量 · 变量设置器　Variable Setters

  用于在载具内创建"全局自定义变量"，实现可被机上任意表达式访问的集中式逻辑与状态管理。
  每个变量设置器每物理帧求值一次。

  XML 中定义在 <Variables> 标签内，格式：
      <Setter variable="Name" function="Expression" priority="0" activator="Condition" />
  设置器在 XML 中的先后顺序，与游戏内 Variable Setter 界面中的顺序一致。

  属性：
      variable   变量的唯一名称。
      function   任何合法的 Funky Trees 表达式，用于计算该变量的值。
      activator  可选布尔表达式，决定该设置器是否激活；不填则始终激活。
                 当表达式求值为 false 时，该设置器被忽略。
      priority   数值，决定优先级。默认为 0，也可取负整数。若多个设置器写入同名变量，
                 则由"激活状态中优先级最高"的那个决定最终输出。

  示例一 · 优先级：
      Setter 1: variable="Mode" function="1" priority="-1"
      Setter 2: variable="Mode" function="2" priority="0"
      Setter 3: variable="Mode" function="3" priority="5"
      若三者都激活，Mode 取 3（优先级最高）；若 Setter 3 被 activator 禁用，则回退为 2。

  示例二 · 激活状态控制：
      Setter 1: variable="Autopilot" function="TargetHeading" activator="Activate1"
      Setter 2: variable="Autopilot" function="0" priority="-1"
      当 Activate1 为真时，Setter 1 激活，Autopilot = TargetHeading；否则由 Setter 2 提供 0。

【2.4】函数　Functions（共 34 个）
--------------------------------------------------------------------------------

  所有函数统一调用格式：functionName(argument1, argument2, ...)
    · 函数名严格区分大小写。
    · 参数写在括号内，多个参数以逗号分隔。
    · 每种函数要求特定数据类型（Number / Boolean / String），类型不匹配会导致求值失败。

  ▸ PID(target, current, p, i, d)
      比例-积分-微分（PID）控制器：根据当前观测值与目标的偏差，计算输出以逼近目标。   [返回 Number]
      参数：target (Number)、current (Number)、p (Number)、i (Number)、d (Number)
      示例：PID(10, AltitudeAgl, 1, 0.5, 2) —— 尝试让飞机维持在 10 米的悬停高度

  ▸ abs(x)
      取绝对值（去掉负号），结果恒 ≥ 0。   [返回 Number]
      参数：x (Number)
      示例：abs(-10) → 10　｜　abs(10) → 10　｜　abs(Pitch) —— 返回俯仰输入的大小（与方向无关）

  ▸ acos(x)
      反余弦，返回角度（度）。   [返回 Number]
      参数：x (Number)
      示例：acos(0.5) → 60　｜　acos(0) → 90

  ▸ ammo(x)
      返回指定武器剩余的弹药量。   [返回 Number]
      参数：x (String)

  ▸ asin(x)
      反正弦，返回角度（度）。   [返回 Number]
      参数：x (Number)
      示例：asin(0.5) → 30　｜　asin(1) → 90

  ▸ atan(x)
      反正切，返回角度（度）。   [返回 Number]
      参数：x (Number)
      示例：atan(1) → 45　｜　atan(0) → 0

  ▸ atan2(y, x)
      由 y/x 的反正切返回角度（度），会根据两参数符号判定正确象限（atan 无法判象限）。   [返回 Number]
      参数：y (Number)、x (Number)
      示例：atan2(1, 1) → 45　｜　atan2(1, -1) → 135　｜　atan2(-1, -1) → -135　｜　atan2(VerticalG, GForce) —— 可求出总 G 力矢量的角度

  ▸ ceil(x)
      向上取整到最接近的整数（正数远离 0，负数趋向 0）。   [返回 Number]
      参数：x (Number)
      示例：ceil(1.1) → 2　｜　ceil(-1.1) → -1

  ▸ clamp(x, min, max)
      把输入值限制在指定的最小/最大边界之间。   [返回 Number]
      参数：x (Number)、min (Number)、max (Number)
      示例：clamp(Throttle, 0.2, 0.8) —— 保证输出不低于 0.2、不超过 0.8

  ▸ clamp01(x)
      把输入值限制在 0~1 之间，等价于 clamp(x, 0, 1)。   [返回 Number]
      参数：x (Number)
      示例：clamp01(Pitch) —— 保证输出始终落在 0~1 区间

  ▸ cos(x)
      余弦，输入角度（度）。   [返回 Number]
      参数：x (Number)

  ▸ deltaangle(a, b)
      计算两个角度（度）之间的最短夹角差。   [返回 Number]
      参数：a (Number)、b (Number)
      示例：deltaangle(Heading, TargetHeading) —— 返回朝向目标所需的最短转角

  ▸ exp(x)
      返回自然常数 e 的 x 次幂。   [返回 Number]
      参数：x (Number)、is raised.

  ▸ floor(x)
      向下取整到最接近的整数（正数趋向 0，负数远离 0）。   [返回 Number]
      参数：x (Number)
      示例：floor(1.9) → 1　｜　floor(-1.1) → -2

  ▸ inverselerp(a, b, x)
      反线性插值：求出使结果等于 x 的比例 t（0~1）。   [返回 Number]
      参数：a (Number)、b (Number)、x (Number)

  ▸ lerp(a, b, t)
      按比例 t 在 a、b 之间线性插值，结果被钳制在 a、b 之间。   [返回 Number]
      参数：a (Number)、b (Number)、t (Number)

  ▸ lerpangle(a, b, t)
      同 lerp，但专为角度设计，能正确处理 360° 环绕。   [返回 Number]

  ▸ lerpunclamped(a, b, t)
      在 a、b 之间按 t 线性插值，但不钳制最终结果（允许外推）。   [返回 Number]
      参数：a (Number)、b (Number)、t (Number)

  ▸ log(x, p)
      返回以 p 为底、x 的对数。   [返回 Number]
      参数：x (Number)、p (Number)

  ▸ log10(x)
      返回以 10 为底的对数，等价于 log(x, 10)。   [返回 Number]
      参数：x (Number)

  ▸ max(a, b)
      比较两值，返回较大者。   [返回 Number]
      参数：a (Number)、b (Number)
      示例：max(Throttle, 0.5) —— 保证输出至少为 0.5

  ▸ min(a, b)
      比较两值，返回较小者。   [返回 Number]
      参数：a (Number)、b (Number)
      示例：min(Altitude, 1000) —— 保证输出不超过 1000

  ▸ pingpong(x, l)
      让数值 x 在 0 到长度 l 之间来回振荡（乒乓）。   [返回 Number]
      参数：x (Number)、l (Number)

  ▸ pow(x, p)
      返回 x 的 p 次幂。   [返回 Number]
      参数：x (Number)、p (Number)

  ▸ rate(x)

      参数：x (Number)

  ▸ repeat(x, l)
      让数值 x 超过长度 l 时回绕，使结果保持在 0~l 之间循环。   [返回 Number]

【2.5】接口　Interfaces（5 个）
--------------------------------------------------------------------------------

  接口指"可以在其中书写并使用 Funky Trees 代码"的各种物理位置，每种接口行为各不相同。

■ InputController　输入控制器
  绝大多数 Funky Trees 用法都在 InputController 内。它可控制大部分 SimplePlanes 部件，
  从发动机到旋转器无所不包。
  XML 中定义在 <InputController.State> 元素，是该 <Part> 的子元素；一个部件有一个输入控制器：
      <Part>
        ...
        <InputController.State activationGroup="Number" invert="Boolean" min="a" max="b" input="Number" />
        ...
      </Part>
  属性：
      activationGroup   见激活组接口页。                        例：Activate1
      invert            决定 input 值施加到部件上的方向，true / false。  例：true
      min               输入范围映射的下界。                     例：0
      max               输入范围映射的上界。                     例：1
      input             用于控制该部件的 Funky Trees 表达式。    例：sum(Pitch)*2
  要点：min / max 看似钳位，实为"映射"：控制器把 input 从 [-1, 1] 映射到 [min, max]。
        例如 input 为 1 时，实际传给部件的输出是 1 * max。这是从 FT 出现之前沿用下来的行为，
        因此更推荐对 min/max 使用部件默认值或 [-1, 1]，让表达式直接传给部件而不被映射。
        若需要钳位，请在 input 内部用 clamp() / clamp01() 实现。
        另注：部件的实际行为不只取决于 input，input 只控制部件相对其其它物理参数（如旋转器的
        旋转范围）如何动作。

■ Activation Group　激活组
  用于控制部件的激活组（activator）逻辑，可用于 InputController、Detacher、Parachute 等，
  各处属性名不完全一致：
      <InputController.State activationGroup="activator" ... />
      <Detacher.State group="activator" ... />
      <Parachute.State activationGroup="activator" ... />
  参数 activator（Number 或 Boolean）：控制激活器的 FT 表达式，任意合法表达式均可。
      最常用、也最推荐用 Boolean。由于布尔量是动态类型，也可以用数字控制：此时数字"大于 0"
      即视为激活。
  示例（对所有实例通用）：
      ... activationGroup="Activate1" ...         经典激活组绑定
      ... group="Altitude>100" ...                高度超过 100m 时激活（如触发器）

■ Debug Console　调试控制台
  在 PC 上按【反引号】键（键盘左上角 Tab 上方）打开，移动端三指点按打开。读取某个 FT 表达式的值，用命令：
      DebugExpression "Expression"
  参数 Expression：要读取的 Funky Trees 表达式。
  内含引号（""，用于字符串）的表达式，必须把引号替换为井号字符（##）。
  示例：
      DebugExpression "Altitude"            读取当前高度
      DebugExpression "1+2"                 求值 1 + 2
      DebugExpression "#SelectedWeapon#"    读取当前选中武器名称

■ Buttons　按钮
  可用鼠标交互的组件，能向输入变量与自定义变量写入，独立于标准部件变量系统。
  XML 中按钮由 <Part> 元素的属性 PartType="Button-1" 定义，含两个子元素：<Button.State> 与
  <Label.State>（此处只讲 <Button.State>）。
      <Button.State inputId="VariableName" style="StyleType" lightStrength="Number" interactionType="TypeName" outputValue="Output" />
  属性：
      inputId          必须是合法的自定义变量或输入变量名；按钮激活时向它写入。
      style            按钮外观类型：Rectangular（矩形）或 Circular（圆形）。
      lightStrength    激活时按钮背光强度，默认 1，为百分比。
      interactionType  按钮行为类型：Once / Continuous / Toggle 三选一。
      outputValue      按钮激活时的输出值，默认 1，可设为任意数字。
  行为要点：
      · inputId：变量可以是该按钮独有的，也可以是变量设置器或部件变量已创建的既有变量。
      · outputValue：按钮激活时，该值会以优先级 0 写入 inputId 指定的变量。
      · interactionType：
          Once        按下时把 outputValue 写入 inputId，持续 1 个物理帧，然后自行复位。
          Continuous  按住期间持续把 outputValue 写入 inputId。
          Toggle      按下时把 outputValue 写入 inputId 并保持开启，除非该 inputId 被其它
                      变量设置器覆盖。
