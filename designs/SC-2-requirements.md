# SC-2：高机动空战验证机 需求与规格书

课题：目标指向（狗斗）飞控。机体由用户在设计师内搭建，本文给出设计约束与验收指标。
命名：**JETaircraft**，另存独立文件（不覆盖 TESTaircraft，保留旧平台回归能力）。

## 一、设计哲学（吸取 SC-1 三条教训）
1. **舵量权限就是包线**——SC-1 高速段 pa 顶死 ~9°，20° 指令是空承诺。本机体副翼/平尾面积按下"高速仍有 ≥20° 可用姿态"配；
2. **能量即生命**——持续爬升 10~15 m/s 追不上任何目标。推重比为第一设计约束；
3. **感知通道决定导引上限**——Lua 只有 `Target.Distance/Name` + 锁定布尔（platform-facts §十七），机体设计要配合"锥内保持"式导引：机头指向精度和滚转速率比传感器重要。

## 二、性能指标（验收线）
| 项 | 目标值 | 测量法 |
|---|---|---|
| 平飞最大速度 | ≥ 140 m/s | 水平加速段 IAS 平台 |
| 推重比（满油战斗构型） | ≥ 0.8 | 静推力/重量，或垂直爬升能维持空速 |
| 稳态滚转率 | ≥ 90°/s | 满杆滚转段 RollRate |
| 瞬时可用过载 | ≥ 4~5 g | 拉起急升段 GForce |
| 持续爬升率 | ≥ 20 m/s | 140 m/s 附近定常爬升 |
| 失速速度 | 记录入册 | 低速试飞，定 V_MIN 新值 |

## 三、构型要求
- **气动**：中等后掠主翼（面积 8~12 m²，比 SC-1 小——高速优先），大边条或前缘缝翼可选；平尾全动（用 Elevator 件当全幅动平尾，面积给足）；单垂尾+方向舵；
- **副翼**：左右各一，**展向占比 ≥ 30%**（滚转率是导引头的命脉）；
- **动力**：喷气发动机为主，目标静推力 ≥ 0.8×起飞重量；油门响应走现有 Throttle 轴；
- **减速**：加减速板（Air Brake）一件——狗斗能量管理用，Lua 暂不接管；
- **CG/静稳**：同 SC-1 方法控制在 MAC 50% 附近、静稳度 5~15%（放宽不静不稳定——内环还是 P-only，撑不住负静稳）；
- **必装件**：
  - **MFD-1**（Lua 通道宿主，老规矩）；
  - **Flight Computer 座舱**（零件附着根）；
  - **Targeting Pod Lite**（50 kg，8 km——锁定锥信标的硬件前提）；
  - **Wing Gun ×1 或 ×2**（提供武器系统/锁定模式，空空弹 Interceptor 可选加装练"发射后逃逸"）；
  - Gyroscope 按现有惯例。
- **不装**：VTOL、自动驾驶仪零件（全部功能走我们自己的 Lua）。

## 四、控制律接口（给 Task 3/4 预留）
- 舵面 FT 表达式保持"同帧 P-only"格式：副翼 `clamp(Roll_cmd - k*RollRate?, ...)` 注意 11.5 Hz 泵振教训——**速率阻尼一律放 Lua，FT 里只留无记忆项**；升降舵 `clamp(Trim + PID(-Pitch*10, PitchAngle, -0.05, 0, 0), -1, 1)` 沿用；
- Lua v7 三轴：Roll/Yaw/Pitch 全 OverrideInput；新增导引外环输入 = `craft.Targeting`（Mode 置 `AirToAir`，读 Target/Distance）；
- MFD 按钮重排：1=AP 电门，2=高度 bug，3/4=目标±100（保留），5=**狗斗模式开关**，6=**NextTarget 手动换目标**。

## 五、开放问题（建机时顺手回答）
1. 单机沙箱里敌机怎么出来？（战争主题任务/活动？还是只有多人局？）——若沙箱无敌机，先用**地面目标 + AirToGround 模式**走通导引链路，敌机局留作多人或任务模式验证；
2. 锁定锥角具体多大（Wing Gun 的 TargetingAngle）——装好后 Lua 打 `craft.Targeting.Mode` + 逐步逼近静态目标实测锥边界；
3. `Targeting.Mode` 从 Lua 写入是否生效（代理有 setter，未实测）。
