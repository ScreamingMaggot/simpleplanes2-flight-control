## E1 · 俯仰阻尼器 ✅ 通过

```
clamp(Trim + Pitch - 0.06*PitchRate, -1, 1)
```

- 用户实测定稿 Kq=0.06（我给的初扫范围 0.01~0.04 偏保守）
- **关键修正（用户做出）**：必须带 `Trim` 前馈。本机无配平时平衡态舵偏是 -9%，
  纯阻尼器以"舵面中立"为回中点，反而制造低头力矩。前馈喂配平、反馈只修残差——
  这就是实际飞控里 trim schedule 的存在理由。

## E2 · 姿态保持（按住 A1 接通）✅ 通过，"操作手感非常棒"

```
Activate1 ? clamp(Trim + PID(0, PitchAngle, 0.05, 0.002, 0.05), -1, 1) : clamp(Trim + Pitch - 0.06*PitchRate, -1, 1)
```

| 增益组 | 现象 | 课本对应 |
|---|---|---|
| Kp=0.05, Ki=0.002, Kd=0.05 | 回中平顺，手感好 | ζ 适中的二阶响应 |
| Kp=0.1（用户实测） | **起振荡** | ωn↑、ζ↓，极点趋向虚轴 |

- 松杆自动改平成功 → C1 的"5 秒低头 20°"被控制律消灭
- 待补测（顺手即可）：Kp=0.05 档"1 秒满杆回中"的过冲角与收敛时间，与手动基线（C2）成表

## E3 · 定高回路（调试过程与最终设计）

**踩坑记录**（全部实证）：
- 左右舵面各写一遍 `PID(...)` = 两个独立积分器 → 不同步抖振。修正架构：**控制律进 Setter 只算一次，执行件只读结果**
- 表达式引用未注册变量名（大小写笔误）→ **整条表达式静默失效**（连手动分支一起死），无醒目报错
- VTOL 轴：控制设置里存在（±100%，弹簧回中），但实测无法作为保持型指令源 → 弃用
- Activate3 等后引入的激活组键位需自行确认绑定

**最终设计 · V/S 垂直速度模式**（Trim 不弹回特性当指令杆）：

```
Setter  AP_Out = PID(Trim*10, rate(AltitudeAgl), 0.15, 0.1, 0)   activator: Activate3
升降舵  Activate3 ? clamp(Pitch + AP_Out - 0.06*PitchRate, -1, 1)
                 : clamp(Trim + Pitch - 0.06*PitchRate, -1, 1)
```

- Trim 杆位=指令爬升率（±10 m/s 满量程），回中=高度冻结；Pitch 全程叠加（共驾式）
- 只用 P+I：被控量 rate(Altitude) 已是高度的导数，再加 D 是噪声放大器
- 待验证：爬升率方向符号、I 增益抖动边界、能量受限时的舵面饱和现象

## E3 事故与升级 · 倒飞挂壁 + 荷兰滚 → 串级 + 偏航阻尼

**事故现象**（用户实测）：V/S 单回路模式下飞机进入倒飞并"稳定"保持；滚转改出时激发荷兰滚振荡。

**归因**：
1. 单回路 V/S 只观测 `rate(AltitudeAgl)`，**不含姿态信息** → 倒飞只要垂直速度满足指令即成平衡点（attitude loss of observability，串级回路存在意义的现场证明）
2. 本机垂尾大（1.95 m²）航向静稳强、无偏航阻尼 → 侧滑-偏航耦合能量不衰减 = 荷兰滚。出厂 P-51 XML 中的 `Yaw*lerp(1,0,IAS/60)-YawRate*0.15*clamp01(AltitudeAgl<1.5)` 即官方同款解药

**升级设计**：

```
AP_Qcmd  PID(Trim*10, rate(AltitudeAgl), 0.15, 0.1, 0)*20   act:Activate3   （外环：V/S误差→期望俯仰角，±20°）
AP_Out   PID(AP_Qcmd, PitchAngle, 0.05, 0.002, 0.05)         act:Activate3   （内环：E2 已验证的姿态 PID）
方向舵   clamp(Yaw - 0.2*YawRate, -1, 1)                                      （偏航阻尼器）
升降舵   不变（Activate3 ? Pitch+AP_Out-0.06*PitchRate : Trim+Pitch-0.06*PitchRate）
```

**重演实验**：故意拉杆失速倒扣，验证串级版自动改出=姿态保护诞生。

## E3 终局 · 定高（纯 P 版）✅ 服役

V/S 串级路线调试中连环受挫（runaway/挂死/转圈），最终简化为单回路 P 控制定高，实测稳定：

```
Setter   AP_Out = PID(500, AltitudeAgl, -0.003, 0, 0)        activator: 3（组号，非布尔式）
升降舵   Activate3 ? clamp(Trim + AP_Out - 0.06*PitchRate, -1, 1)
                 : clamp(Trim + Pitch - 0.06*PitchRate, -1, 1)
方向舵   clamp(Yaw - 0.2*YawRate, -1, 1)                      （偏航阻尼，抑制荷兰滚）
```

### 平台级教训（本次调试的三大发现，全部实测）

1. **时间增益按物理拍折算**：Setter/PID 每拍求值（≈50 Hz），按"每秒"设计的 I/D 增益实际放大约 50 倍 → 秒级积分瞬间饱和。i 起步值应为按秒设计值 ÷ 50
2. **高度环增益符号与姿态环相反**（姿态环 +0.05 正常，高度环需 -0.003 才收敛）→ `AltitudeAgl`（或 PID 误差序）存在与文档直觉相反的符号约定，**待标定实验**（见下）
3. **Setter activator 填激活组编号**（`3`），不是布尔表达式；SP1 社区文档在 SP2 上会误导

### 待办

- [ ] 残差消除：i 从 -0.00002 起步逐加，出现到点冲过头即回调
- [ ] **符号标定实验**：`AP_Out = Time/50` 直驱升降舵，看舵面从哪端扫到哪端，一次钉死"正输出=抬头还是低头"；再用已知爬升验证 `AltitudeAgl` 单调性
- [ ] 把 E2 姿态保持（A1）拼回三模态优先级链：定高 > 姿态 > 手动阻尼
- [ ] 横航向补全：副翼滚转阻尼 `Roll - k*RollRate` + 航向保持 `deltaangle(Heading_cmd, Heading)`
- [ ] 记录 E3 事故链为教学案例：单回路丢姿态观测 → 倒飞挂壁；正反馈 → 发散转圈；积分按拍放大 → 饱和失控

## E2 修正 · 姿态指令律（符号法典裁决后）✅ 实飞"相当稳"

E2 原版正增益经复测判定为**正反馈**（"几乎无法控制"），当年手感系 Trim+静稳掩盖。
符号法典（platform-facts §十）修正版实飞验证稳定，且发现杆-姿态指令形态：

```
AP_Qcmd = -Pitch*10          （杆位→姿态指令，推杆为正故取负）
AP_Out  = PID(AP_Qcmd, PitchAngle, -0.05, i, 0) - 0.06*PitchRate
升降舵  = clamp(Trim + AP_Out, -1, 1)
```

- PID 的 d 参数经实测引发舵面抖动（帧采样微分尖峰），**归零**；阻尼一律原生 PitchRate 显式项；
- 杆效反号第一次复现（`+Pitch*10` 拉杆反而低头）= 法典第 4 次自证；
- 姿态指令模式下杆感天然"肉"（点单-执行结构），指令梯度 `*10` 是飞行品质参数，可调 `*15`；
- 与 E3 统一成单架构：A3 接通时 Qcmd 换源为高度环输出（activator 弃用，门控写进函数三元，
  不成立时 PID 不被调用、积分器自然冻结）——见 platform-facts §十六（如另开）。

同一个升降舵通道，三行字完成了从"人操飞机"到"指令飞行"的跨越：
前馈（Trim）+ 比例（姿态回中）+ 微分（阻尼）+ 小积分（消残差）。
下一步 E3 把被控量从姿态换成高度，正式进入**回路级联与积分饱和**的地盘。
