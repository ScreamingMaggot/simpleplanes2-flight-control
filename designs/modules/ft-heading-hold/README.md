# FT 航向保持模块（可复用技术点）

**一句话**：纯 FT 的"**松杆保持当前航向 / 带杆全权限**"，横向环与纵向（`ft-altitude-hold`）对称设计。
首验载体 `TESTaircraft2`（2026-09-25，SC-6），可与高度模块叠加使用。

## 1. 原理

```
psiTgt = atan2( smooth(sin(H), 动杆?9999:0), smooth(cos(H), 动杆?9999:0) )   # 目标航向（松杆冻结）
hdgErr = deltaangle(Heading, psiTgt)                        # 最短转角，正=目标在右
bankCd = -clamp(1.2 * hdgErr, -30, 30)                      # 右转需要负坡度（RollAngle 正=左坡）
phiCmd = cmdPhi + hold * bankCd                             # 杆量 + 松杆时的航向外环
副翼   : GATE ? clamp(0.010*(RollAngle - phiCmd) + 0.004*RollRate, -1, 1) : Roll
```

**两个关键写法**：
1. **抓取要绕圈安全**：`Heading` 在 ±180 折返，直接 `smooth(Heading, rate)` 跨 ±180 时会被拉成一整圈。
   正解是对 **`sin` 与 `cos` 分量各自做限速跟随**，再用 `atan2(sin,cos)` 还原角度（分量冻结=方向冻结）✓ 本模块即此写法。
2. **误差用官方 `deltaangle(a,b)`**（最短转角，degrees），不要自己 wrap。

## 2. 与高度模块共享的三件事（别重复实现）

| 共享件 | 说明 |
|---|---|
| `hold` 门控 | `smooth(动杆?0:1, 2)`：手操时外环 0.5 s 淡出、松杆 0.5 s 淡入。航向环与高度环**共用同一个 `hold`** |
| `GATE` | `(Activate8 & (boot > 0.5))`：8 号默认开=开机自持；`boot` 软启动防第 0 帧抢杆 |
| 内环 | 滚转内环 `0.010/0.004`（SC-3b 已验证）、俯仰 `0.040/0.007` |

## 3. 语义边界（横风测试要看懂的两件事）

- **航向保持 ≠ 航迹保持**：它 hold 的是**机头指向**。侧风下飞机保持机头方向、航迹被吹偏——这是正确行为（真实飞行的"航向模式"亦如此）。
- 若要**压着地面航线飞（航迹不被吹偏）**，那是另一层：**地速航迹环**——用 `rate(Latitude)`/`rate(Longitude)`（世界系速度分量，米制）或对目标航迹用 `deltaangle` 做外环 ⇒ Droplet 那套世界系位置-速度串级的横向部分。**本模块不含**。

## 4. 判据（横风局）

| 看什么 | 合格 |
|---|---|
| 松杆后 `H`（实际航向）| 稳住不漂，`T`（目标）不随飞机变 |
| 横风中 | 机头指向被守住（航迹漂移是正常的，见 §3） |
| 摆动 | 无周期 >5 s 的慢摆；有则先把 `1.2` 降到 `0.8`，再降坡度限 `30→20` |
| 带杆 | 全权限（`hold=0` 时横向外环完全让位，与高度环一致） |

## 5. 调参账

| 参数 | 值 | 说明 |
|---|---|---|
| 航向增益 | **`1.2`（定版）** | app18 试 2.4 被用户判"不太行"⇒ 已回滚。1.2 时 25° 误差打满 30° 坡度 |
| 坡度限 | `±30°` | 正切转弯率：30° 坡 @60 m/s ≈ 9.5°/s 航向变化率 |
| 与高度环共用 | `hold` / `GATE` / 内环增益 | 见 §2 |
