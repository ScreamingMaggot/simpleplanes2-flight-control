# FT 航迹保持模块（地速坐标系 · 自动降落横向的底子）

**一句话**：纯 FT 的"**松杆压住当前地面航线（含横风自动偏流）/ 带杆全权限**"。
与 `ft-altitude-hold`、`ft-heading-hold` 同族，共用 `hold` 门控与 `GATE`；**与航向保持二选一**（`Activate1` 默认开=航迹保持，关=航向保持）。
首验载体 `TESTaircraft2`（2026-09-25，SC-6），用户点名"B 方案：为后续自动起降打基础"。

## 1. 原理（与航向保持的区别）

| | 航向保持 | **航迹保持** |
|---|---|---|
| 控什么 | 机头指向 (`Heading`) | **地速航迹** (`atan2(dE/dt, dN/dt)`) |
| 横风下 | 机翼水平、**航迹被吹偏**（侧滑 −8.5° 实测） | **自动压出偏流角（crab）**、航迹不偏 |
| 传感器 | `Heading` | **`rate(Latitude)` / `rate(Longitude)`**（世界系速度分量，米制） |
| 用途 | 巡航保持方向 | **进近压线 / 自动降落横向** |

## 2. 表达式（面板按序）

```
动杆 = ((abs(Roll) > 0.05) | (abs(Pitch) > 0.05))        # 手操判据（全文件共用）
trkNow = atan2(rate(Longitude), rate(Latitude))           # 当前地速航迹（罗盘度）
latTgt = smooth(Latitude,  动杆 ? 9999 : 0)               # 松杆抓「当前点」
lonTgt = smooth(Longitude, 动杆 ? 9999 : 0)
tSin   = smooth(sin(trkNow), 动杆 ? 9999 : 0)             # 松杆抓「当前航迹」——按分量冻结，
tCos   = smooth(cos(trkNow), 动杆 ? 9999 : 0)             #   避免 ±180 折返被拉成一圈
trkTgt = atan2(tSin, tCos)
xtrack = (Latitude - latTgt) * sin(trkTgt) - (Longitude - lonTgt) * cos(trkTgt)   # 横偏（米，正=线左侧）
trkErr = deltaangle(trkNow, trkTgt)                       # 航迹误差（正=需右转）
bankTrk = -clamp(trkErr + clamp(0.15 * xtrack, -20, 20), -30, 30)
phiCmd  = cmdPhi + hold * (Activate1 ? bankTrk : bankCd)  # 横向外环二选一
```

**符号推导（不是猜）**：横偏为正=飞机在线的**左侧** ⇒ 需右转 ⇒ **负坡度**（本机 `RollAngle` 正=左坡）⇒ `bankTrk = -clamp(…)`；航迹误差为正=需右转 ⇒ 同样取负。1:1 的"航迹误差→坡度"是标准做法（横偏先经 `0.15°/m 钳 ±20°` 变成切入角，再与航迹误差合并）。

## 3. 抓取语义（关键）

**松杆那一刻**同时抓住：
- **当前点**（lat/lon）⇒ 决定航线位置；
- **当前地速航迹**（含此刻的偏流角）⇒ 决定航线方向。

⇒ 要压哪条线，就在那条线上、沿航迹方向飞着的时候**松杆**。之后外环把飞机拉回这条线并沿线飞（横风里自动 crab）。
动杆时两个目标都跟随当前状态（相当于"目标=自己"），所以手操期间外环不会攒账。

## 4. 判据（首验）

| 看什么 | 合格 |
|---|---|
| Label 42 的 `X`（横偏，米） | 松杆后收到 **±20 m 内并保持** |
| 横风下 | 机头**偏离**航迹方向（crab），但 `X` 不持续增大 ⇒ 压线成功 |
| 关 1 号切回航向模式 | 行为回到上一版（航迹被吹偏、侧滑稳定）|
| 摆动 | 无 S 形慢摆；有则先降 `0.15→0.08`，再降切入角钳位 `20→12` |
| 低速 | `GS < ~40 m/s` 时 `rate(Lat/Lon)` 噪声大、`trkNow` 不可信 ⇒ 本环仅在空中中高速用 |

## 5. 与自动降落的关系

SC-3b 的 Lua 着陆律核心就是"**压住延长线 + 高度-距离剖线**"；本模块 = 它的纯 FT 横向版（不含程序段/盘旋）。
下一步把它接成"目标线 = 跑道延长线（由起飞点或跑道数据给出）"，横向就与 SC-3b 等价；纵向再叠 `altitude-hold` 的距离剖面，即构成纯 FT 的进近下沉。

## 6. 首验数据侧观察（app25，粗筛）

用户口述"**效果倒是不错**"。数据侧（从 `POS` 差分重建地速航迹、与 `TEL` 杆量对齐取松杆窗）能看到两件事：
- **存在整段松杆窗，地速航迹标准差仅 1.19°**（cid 97306，481 个松杆样本）⇒ 压线能压得很紧；
- **偏流角（航向 − 航迹）实测出现 −12.6° 的均值**（cid 7489）⇒ **crab 真的发生了**（横风被自动压掉）。

⚠ 该粗筛把"同一日志里多段/未接通窗口"混在一起，所以另几个 cid 算出 36°/122° 的标准差不代表律失手（里面含手操转弯段）。**精确判据以座舱 Label 42 的 `X`（横偏米）为准**：松杆后应收到 ±20 m 内并保持。

## 7. 开局标定规则（app27/28 实飞修出来的）

**病**：外环在开局那一瞬就"信任"了 `rate(经/纬)` 算的地速航迹，而 **`rate()` 开头几帧没有历史 ⇒ atan2(0,0)=0 ⇒ 目标航迹被判成"正北"** ⇒ 飞机开局自己转弯（用户两次实报）。
**修**（用户给的方向）：
```
trkGd = ((Time > 0.5) & (AltitudeAgl > 20) & (GS > 25))     # 起步 0.5 s 内不信地速航迹
trkUse = trkGd ? trkNow : Heading                            # 不信时用**机头方向**当代理
fol    = (Time < 0.5) | (AGL < 20) | (GS < 25) | 动杆         # 起步/地面/低速/手操 ⇒ 目标跟随
```
⇒ 开局标定的就是 **出生点 + 出生机头方向**（停在跑道上时机头=跑道方向），等价 SC-3b 的 `RWY AUTOCAP`，**也就是自动降落的横向起点**。
