# FT 高度自持模块（可复用技术点）

**一句话**：纯 Funky Trees 实现"**松杆定高 / 带杆机动**"——不用 Lua、不用 MFD，整机文件自带。
首验载体 `TESTaircraft2`（2026-09-25，SC-6），本目录是把这块单独摘出来便于移植到别的机体。

## 1. 原理（三句话）

1. **定高本质 = 把爬升率压回 0**：外环 P（`0.8·vsErr`）+ **有界积分**（`vsInt`）驱动俯仰指令；内环是既有的姿态电传。
2. **松杆锁定当前高度**用 `smooth()` 的"限速跟随"实现：`smooth(Altitude, 动杆 ? 9999 : 0)` —— 动杆时以极高速率跟随当前高度（相当于"目标=飞机"），松杆时 `rate=0` **冻结**（真·锁存，不需要自参照）。
3. **积分抗 windup 靠外部**：FT 的 `PID(...,i,...)` 内部没有抗饱和，所以用 `sum()` 自己积，**外部 `clamp(±8°)` 封顶**，并且**只在松杆时积**（不跟飞行员抢杆）。

## 2. 平台原语（官方定义，别凭感觉）

| 原语 | 语义 | 出处 |
|---|---|---|
| `smooth(x, rate)` | **每秒最多变化 `rate`**（限速跟随）；**`rate=0` 即冻结** | 官方 functions/smooth 页 |
| `sum(x)` | **∫x dt**，帧率无关，从关卡加载起积分（实测 `sum(1)` 每秒 +1 吻合） | 官方 functions/sum 页 + 实机自证 |

## 3. 面板 setter（**顺序即求值顺序，只能引用排在它前面的名字**）

```
boot    = clamp01(Time * 0.25)                                        # 4 s 软启动（2 s 后过半）
cmdPhi  = -60 * Roll                                                  # 横向：坡度指令（纯杆量，本模块不改它）
vs      = rate(Altitude)                                              # 爬升率真源（必须在用它的 setter 之前）
altTgt  = smooth(Altitude, 动杆 ? 9999 : 0)                            # 动杆=跟随当前高度，松杆=冻结=锁定目标
vsLim   = (IAS > 42 ? 20 : 5)                                         # 高度环权限：±20 m/s；<150 kph(≈42 m/s) 收 ±5
vsCmd   = clamp(0.25 * (altTgt - Altitude), -vsLim, vsLim)            # 爬升率指令
vsErr   = vsCmd - vs
vsInt   = clamp(sum(松杆 ? vsErr * 0.45 : 0), -8, 8)                  # 有界积分（抗 windup + 不抢杆）
hold    = smooth(动杆 ? 0 : 1, 2)                                    # 外环门控：手操时 0.5 s 内淡出到 0（完全让位）
cmdThe  = min(-30 * Pitch + hold * (0.8 * vsErr + vsInt), (IAS < 45 ? 8 : 90)) # 俯仰指令；IAS<45 抬头封顶 8°
```
其中"动杆"= `((abs(Roll) > 0.05) | (abs(Pitch) > 0.05))`，`cmdPhi`/`cmdThe` 被零件式引用（见 §4），`vs`/`vsInt` 同时用于读数。

## 4. 零件接线（每零件一行）

```
门 GATE = (Activate8 & (boot > 0.5))
副翼  : GATE ? clamp(0.010 * (RollAngle - cmdPhi) + 0.004 * RollRate, -1, 1) : Roll
升降舵: GATE ? clamp(0.040 * (PitchAngle - cmdThe) - 0.007 * PitchRate, -1, 1) : clamp(Trim + Pitch, -1, 1)
```
**门为什么是 8 号 + boot**：8 号激活组默认开启 ⇒ 开机即自持（好用）；串 `boot` 是为了不让它在第 0 帧抢杆；面板整块失效时 `boot=0` ⇒ **自动退回原生手动**（失效安全）。

## 5. 调参账（都是实飞反馈，不是拍脑袋）

| 参数 | 值 | 来历 |
|---|---|---|
| 外环 P | `0.8` | 初版即定；未出现慢振 |
| 积分增益 K | `0.08 → 0.3 → 0.45 → 1.2` | 用户四次反馈"收敛太慢/再激进些"，逐次加倍 |
| 积分封顶 | `±8° → ±20°` | 用户判"0.45 时十几秒就顶满、积分被憋死" ⇒ 放宽；**大封顶=大 windup，慢振时先退封顶再退 K** |
| 权限 `vsLim` | `±20`（<42 m/s 收 `±5`） | 用户定：满幅度给 20，低速保护姿态 |
| 内环 | 滚 `0.010/0.004`、俯 `0.040/0.007` | 取自已飞验证：SC-3b 着陆内环 / FT-Lite 松杆落地 |

**验收（2026-09-25，K=1.2 / 封顶 ±20）**：用户实测定高**过冲约十几米**，判"尚可" ⇒ 本模块定版。
退参顺序（若换机体后出现过冲/慢振）：**先退封顶 20→12 → 再退 K 1.2→0.8 → 最后退 P 0.8→0.6**（低速失速门是独立的下游闸，不动）。

## 6. 观测（座舱 Label）

```
左: {round(IAS)}m/s {round(AltitudeAgl)}m
右: {round(vsCmd*10)/10}/{round(vs*10)/10} I{round(vsInt*10)/10}      # 指令 / 实际 / 积分项
```
- **容量由 `width` 决定，`fontSize` 只影响字大小**（实测：0.3→1.2 才把 `A51B C320D` 全显出来）；
- 显示数值**带小数**（`round(vs)` 会把 −0.4 显示成 0，害人）。

## 7. 移植检查清单（换机体必改）

1. **零件 id**（副翼/升降舵）——本模块在 TESTaircraft2 上是 11/30 与 12/17；
2. **舵面符号**——本机标定：Roll 轴正→坡度负、Pitch 轴正=推杆→低头、PitchRate 正=低头（别的机体要重标）；
3. **失速门阈值** `IAS<45` 与 **权限阈值** `42`（都是 m/s！游戏 UI 显示 kph）——按新机体的失速速度换算；
4. **增益**（外环 0.8 / K 0.45 / 内环 4 个数）——按新机体的操纵效能整定；先用遥测做阶跃辨识（见 SC-6 文档），别硬调；
5. **两个文件同写**：命名机体（机库出击）+ `__editor__.xml`（设计器试飞）——只写一份 = 白改。

## 8. 已知边界（不是 bug）

- **怠速时环会顶到 `+vsLim`**：发动机没有能量维持高度，环在尽力要爬升 ⇒ 读数会是"指令 +20 / 实际 −6"，这是**推力不足**，不是控制器失效；
- **爬升兑现受推力限制**：本机持续爬升实测 ~5.5 m/s（见 `../ta2-envelope.md`），命令给到 +20 也没用；
- **面板不能写 `ActivateN`**：会触发"整面失效"（app59 类），开关量一律在**零件上下文**读；
- **`smooth`/`sum` 的语义已查官方页**，但若换了游戏版本，先复跑一次自证探针（`sum(1)` 应≈秒数）。

## 9. 载体约定：**本机不装 MFD**（2026-09-25 用户定）

游戏级 Lua addon（`telemetry-addon.lua`，打进 `resources.assets`）是按"机体里有 **MFD-1** 零件的实例"逐架挂钩的：机库/座舱按钮回调、Lua AP 高度环、SC-3b 着陆律、遥测 `TEL/POS/ALARM` 都在那上面。本机改用纯 FT 自持后，那套 Lua **与 FT 功能重复**，而且会用 `OverrideInput` 抢 `Pitch/Throttle` **与 FT 打架**（按 1 号键就会发生）。

⇒ **`TESTaircraft2` 摘掉 MFD 零件**（`ft_ta2_patch.py` 默认行为，`--keepmfd` 可保留）：这架机上 Lua 一个钩子都不挂，天地都是 FT 的。代价=这台机没有遥测流，判读靠 Label + 人眼；需要我做数据诊断时临时 `--keepmfd` 飞一局再摘掉。其他机体（如 SC-3b 的 `TESTaircraft`）不受影响。

## 10. v0.7 目标源变更：**VTOL 滑块当高度窗**（用户 2026-09-25 定）

```
altTgt = VTOL > 0 ? 500 + 1500 * VTOL : 500 + 500 * VTOL     # 分段线性
```
| VTOL | 目标高度 (AMSL) |
|---|---|
| +100% | 2000 m |
| 0% | 500 m |
| −100% | 0 m（地面） |

⇒ 目标高度从"松杆抓当前高度"改为**飞行员用 VTOL 旋钮设定**（像高度窗；开机默认 VTOL=0 ⇒ 目标 500 m，离地后自己爬过去）。
⚠ 锚点用的是 **AMSL 绝对高度**；若"地面"要指当前场地标高，需改用 `Altitude - AltitudeAgl`（待用户确认）。

**同步新增：空中门** `airb = clamp01((AltitudeAgl - 5)/5)`，两个外环都改成 `hold * airb * …`：
- 地面上（AGL<5 m）外环完全不出手 —— 这是 SC-1 "滑跑滚翻" 的老账（外环在地面下舵）；
- 离地 10 m 以上全开。姿态电传（`-30·Pitch` / `-60·Roll` 与内环）**不受此门限制**，地面也有手感。
